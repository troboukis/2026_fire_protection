# FireWatch open data

Τα δεδομένα δημοσιεύονται σε μορφή CSV και ενημερώνονται καθημερινά από τη βάση δεδομένων του FireWatch.

- `procurements.csv`: δημόσιες συμβάσεις με πληρωμές, δικαιούχους, κωδικούς CPV και καταγεγραμμένες εργασίες.
- `diavgeia.csv`: αποφάσεις της Διαύγειας και οι συσχετισμένοι δικαιούχοι.
- `current_fires.csv`: καταγεγραμμένα ενεργά και παλαιότερα συμβάντα του πίνακα τρεχουσών πυρκαγιών, μαζί με συνδεδεμένες ειδοποιήσεις 112.
- `copernicus_fires.csv`: συμβάντα πυρκαγιών Copernicus και γεωγραφική αντιστοίχιση.

Τα πεδία που περιέχουν πολλαπλές τιμές, όπως CPV, εργασίες και ειδοποιήσεις 112, αποθηκεύονται ως JSON arrays μέσα στο αντίστοιχο κελί του CSV. Οι κενές τιμές αντιστοιχούν σε `NULL` της βάσης δεδομένων.
